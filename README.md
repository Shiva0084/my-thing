# The Moon

A cinematic one-page experience built for mobile.

Told through the light of a single moon.

## Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- GSAP (ScrollTrigger)
- Lenis
- Lucide React
- next/font

## Sections

1. **Landing** — "Hi. This website was made for one person."
2. **Memory** — "You once called me your Moon."
3. **Dialogue** — Subtitle-style movie dialogue
4. **Truth** — "I owe you the truth."
5. **Responsibility** — "Life has changed me."
6. **Apology** — Three cards
7. **Admiration** — "I admire your kindness."
8. **Growth** — "I cannot change the past."
9. **Acceptance** — "I don't expect anything from you."
10. **Ending** — "You once called me your Moon."

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy

Deploy directly on Vercel — no configuration needed.
